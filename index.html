Publicar directo a GitHub (opcional)

Sin token, “Publicar” descarga data.json para que lo subas al repositorio. Con token, el botón guarda directo y tu socio lo ve en 1–2 minutos.

  1. Entra a github.com → Settings → Fine-grained tokens → Generate new token.
  2. Repository access: “Only select repositories” → vto-frutos-chavez.
  3. Permissions → Repository → Contents: “Read and write”. Nada más.
  4. Copia el token y pégalo aquí. Se guarda sólo en este navegador, nunca en el repositorio.
